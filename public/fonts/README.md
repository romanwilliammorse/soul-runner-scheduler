# Soul Runner typography

The current UI uses the exact self-hosted WOFF2 files served by
https://soul-runner-leagues.vercel.app/styles.css, retrieved on 2026-11-07:

- `barlow-condensed-latin-600-normal.woff2`
- `barlow-condensed-latin-700-normal.woff2`
- `barlow-condensed-latin-800-normal.woff2`
- `barlow-condensed-latin-800-italic.woff2`
- `inter-latin-wght-normal.woff2`

Source URLs are `https://soul-runner-leagues.vercel.app/fonts/<filename>`.

Barlow Condensed is by The Barlow Project Authors (https://github.com/jpt/barlow).
Inter is by The Inter Project Authors (https://github.com/rsms/inter).
Both are licensed under SIL Open Font License 1.1. The full licenses are included
as `BarlowCondensed-OFL.txt` and `Inter-OFL.txt`, respectively, from the official
Google Fonts repository (`ofl/barlowcondensed/OFL.txt` and `ofl/inter/OFL.txt`).

The branding image in `../soul-runner-logo.png` was copied from the user's
reference site at `https://soul-runner-leagues.vercel.app/logo.png` for this
requested visual match. It is separate from the font licenses.
