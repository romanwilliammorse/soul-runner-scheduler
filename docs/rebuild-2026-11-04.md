# Interface rebuild — November 4, 2026

## Scope and preservation

The served interface was rebuilt in `app/league-app.tsx` and `app/availability-grid.tsx`. It replaces the old `scheduler.tsx` entry point. Existing server APIs, credentials, database schema, team links, and saved hours remain in use. No production records or authentication settings were changed. The phase-one scope follows the user's later pivot: registration, recurring availability, owner overlap review. Opposing-team matching and mutual game confirmation remain outside this phase.

## Reuse decisions

- **React Schedule Selector** — https://github.com/bibekg/react-schedule-selector. Reused its MIT-licensed rectangle selection implementation and date utilities in `vendor/schedule-selector`, pinned to the commit recorded in UPSTREAM.txt. Updated date-fns imports. The new wrapper adds numeric weekly-slot mapping, pointer capture, keyboard navigation, and optional touch painting. The original package carries old date-fns and CSS-in-JS dependencies; using the small relevant source avoids introducing them. This is an adapted selection engine, not a fork of the entire application.
- **Rallly** — https://github.com/lukevella/rallly. Evaluated as a complete scheduling app. Its date/time polling workflow does not directly implement the requested recurring roster-based availability and owner/player access model. No Rallly source was incorporated.
- **When2meet clone** — https://github.com/Nat1anWasTaken/when2meet. Evaluated; its Svelte/PostgreSQL application and OAuth setup would require replacing the existing hosting/authentication system. No source incorporated.
- **OR-Tools** — https://github.com/google/or-tools. Relevant to future season optimization; not needed for this phase's exact intersection of recurring player hours.
- **Hugging Face search** — https://huggingface.co/datasets/SCHEDBench/SCHEDBench and https://huggingface.co/papers/2306.05747. Located scheduling benchmarks and research, not a drop-in recurring team-availability application. No model or dataset was added; availability results remain deterministic.

These are fit assessments for this application, not a claim that one project is universally best.

## Typography

Inspected the rendered https://nba.2k.com/2k27/ page in the browser. Its major headings report Sharp Grotesk Variable, weight 700, italic. Used self-hosted SIL Open Font License Barlow ExtraBold Italic for heavy headings and Barlow Condensed Bold Italic for league branding and secondary headings. Font licenses are shipped in `public/fonts/`. This approximates the reference's treatment; it does not reproduce the proprietary typeface or logo.

## Verification performed

- Existing 26 API/time-zone tests passed, including 75 players across 15 teams making 750 availability updates, identity isolation, stale revisions, PIN claiming, CSRF, daylight-saving and fractional-offset zones.
- Two new tests passed against the imported rectangle selector: both drag directions, single cells, midnight, and all 168 weekly slots.
- TypeScript check and production Worker/client build passed.
- Browser, disposable local records: owner sign-in; player-view toggle; single-cell mouse and Space-key selection; unsaved-navigation dialog; save and reload persistence.
- Desktop mouse drag over a 3-day by 2-hour rectangle added exactly 6 slots (28 to 34 total); save succeeded.
- Five-player fixture produced a 2-hour shared window. Copied proposal contained the exact date, time zone, all five names, duration, and an explicit not-booked label.
- Responsive measurements: 390 px viewport / 375 px document and 320 px viewport / 305 px document, with scrollbar; no horizontal overflow.

## Limits

Desktop browser automation with phone-sized viewports does not establish usability on a physical touch phone. Touch scrolling/painting and screen-reader behavior need device testing. No real owners or players participated in this verification. No numerical usability rating is assigned. The earlier assessment document contains ratings that were subsequently acknowledged as overstated; this report does not adopt those scores.
